# Agnes Erika — Product & Visual Design Portfolio

A responsive personal portfolio presenting product design, UI/UX studies, brand systems, campaign design, and social content experiments.

## Design direction

The website combines:

- Swiss-inspired typography and grid structure
- Brutalist borders, offset shadows, and direct visual hierarchy
- A warm editorial colour system with light and dark modes
- Project-led storytelling inspired by modern creative studio portfolios
- Clear status labels that distinguish functional prototypes from work in progress

## Portfolio structure

1. **Selected Product Work** — Lunaria, FitFinder, Clown Color Picker, Guestaeat Café, and Sunflower Bloom Tracker
2. **UI/UX Collections** — mobile flows, component studies, and web interface concepts
3. **Brand & Campaign Design** — Nori Matcha, Paradiseto Chocolato, and Paloma Grazia
4. **Social Design Playground** — personal carousel and campaign experiments
5. **About & Contact**

## Features

- Responsive desktop, tablet, and mobile layouts
- Light and dark themes
- Project status filters
- Mini case-study dialogs with challenge, response, user flow, and scope
- Live website buttons for functional and experimental web projects
- Reduced-motion support and keyboard-accessible controls

## Running locally

Open `index.html` in a browser. No build step or package installation is required.

## GitHub Pages

The site can be published from the repository root:

1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select the branch to publish and the root `/` folder.
4. Save the configuration.

The repository can remain private while the GitHub Pages site is public only when the account and repository settings support private-repository Pages. Otherwise, publish after making the repository public.

## Project honesty

The portfolio intentionally identifies incomplete prototypes as works in progress. It does not claim fictional metrics, rankings, clients, or completed functionality.
